# AI Brain Fog Test / AI 脑雾人格测试

一个**规则驱动、AI 辅助交互、像素人格呈现**的娱乐化认知校准测试。

它不测智商，也不让模型主观评判用户。AI 只负责场景化表达、开放输入解析和结果文案；分数和人格全部由确定性规则计算。

## 测量维度

- **AI 权威依赖**：是否因为 AI 的语气、完整度或“多数模型一致”而放弃判断。
- **验证惰性**：通过“原始资料、另一个AI或直接采信”等题内答案判断验证习惯。
- **自信失准**：通过答案中的确定性程度与实际判断质量评估认知校准。
- **理解幻觉**：通过改变关键条件后的迁移答案评估是否真正掌握。

## 核心原则

> AI 负责让测评像活的，规则负责让分数是死的。

## 快速开始

需要 Python 3.11+。

```bash
python -m pip install -e .
ai-brain-fog
ai-brain-fog --responses data/responses.demo.json
# 未安装包时也可直接运行
python3 scripts/run_assessment.py --responses data/responses.demo.json
pytest
```

不传 `--responses` 时进入包含 12 个情境的交互流程。测评没有标准答案，用户只需选择最符合真实反应的选项；每个情境的选项会独立随机排序，同一情境在 AI 提示前后保持稳定。

编程、学习、职场、商业、新闻和综合六个入口分别拥有 20 道完整独立题目，共 120 道。不同场景共享评分构念与选项分值以保持结果可比，但不通过关键词替换生成题面。

每个场景题池包含 10 道基础题、6 道 AI 干扰题和 4 道理解迁移题。每次测试分层随机抽取 6+4+2 共 12 道，评分器按实际题目 ID 校验并从答案变化中派生行为事件。

当前题库覆盖来源核查、因果推断、可信度评估、形式逻辑、长链论证审计、引用链、代码行为、抽样偏差和条件迁移。AI 意见介入情境只记录提示前后的选择，不展示标准解释或追加问题。

## 总分公式

```text
首版 AI 脑雾指数
= (AI权威依赖 × 30%
 + 验证惰性 × 25%
 + 自信失准 × 30%
 + 理解幻觉 × 15%)
```

四个维度和人格行为信号都从题内答案计算，不需要单独采集核查方式、置信度或其他元数据。

人格不是单纯按照总分切区间，而是由可观察行为和维度组合判定。例如：

- 多次在 AI 强势提示后放弃原选择并跟随 AI → `AI 授权懂王`
- 只用多个模型互相复核，从不看原始材料 → `多模投票教徒`
- 声称掌握但迁移题失败 → `迷雾操作员`

## 生产实现建议

图像模型只生成无文字角色素材；最终标题、分数条和标签由程序渲染，避免中文错字和数值漂移。

## 规则与内容

- `rules/scoring.json` 是权重、行为分值、人格分类和改进建议的唯一规则源。
- `data/questions.json` 是六场景、每场景 20 题的版本化题库。
- `data/personas.json` 提供 8 种人格的固定文案和素材引用。
- `data/responses.demo.json` 是可重复运行的完整结构化回答示例。
- `assets/assessment-widget.html` 是会话内点击式测评组件；每个情境只收集选择，并在组件内直接完成确定性评分和结果展示。结果页可重新测试，或将完整结果生成为 PNG 卡片后调用系统分享、复制或下载。
- `scripts/sync_widget_questions.py` 将题库、规则、人格和八张结果卡同步进离线组件；修改这些源数据后需重新运行。

## Disclaimer

这是娱乐化 AI 素养测试，不构成智力、心理或临床评估。
