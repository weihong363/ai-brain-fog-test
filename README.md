# AI Brain Fog Test / AI 脑雾人格测试

一个**规则驱动、AI 辅助交互、像素人格呈现**的娱乐化认知校准测试。

它不测智商，也不让模型主观评判用户。AI 只负责场景化表达、开放输入解析和结果文案；分数、人格和证据全部由确定性规则计算。

## 测量维度

- **AI 权威依赖**：是否因为 AI 的语气、完整度或“多数模型一致”而放弃判断。
- **验证惰性**：是否查看原始资料或真正独立的来源。
- **自信失准**：置信度与实际正确率是否匹配。
- **理解幻觉**：是否把“看懂解释”误认为“能够迁移应用”。

## 核心原则

> AI 负责让测评像活的，规则负责让分数是死的。

## 快速开始

需要 Python 3.11+。

```bash
python -m pip install -e .
python scripts/demo.py
pytest
```

演示输入会输出四维分数、总指数、人格 ID 和行为证据。

## 总分公式

```text
AI 脑雾指数
= AI权威依赖 × 30%
+ 验证惰性 × 25%
+ 自信失准 × 30%
+ 理解幻觉 × 15%
```

人格不是单纯按照总分切区间，而是由可观察行为和维度组合判定。例如：

- 多次将正确答案改成 AI 的错误答案 → `AI 授权懂王`
- 只用多个模型互相复核，从不看原始材料 → `多模投票教徒`
- 声称掌握但迁移题失败 → `迷雾操作员`
